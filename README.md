# 签名板 · Sign Pad

一个单文件的网页手写签名板。打开就能写，写完导出透明 PNG，直接插进 Word、PDF 或线上表单。

> A single-file browser-based signature pad. Draw with mouse, touch or stylus, export a transparent PNG. No build, no dependencies, no network.

## 特点

- **无构建、无依赖** — 纯静态 `index.html`；PDF 功能另带一个 `vendor/pdf-lib.min.js`，点开 PDF 面板时才加载，不影响首屏
- **不联网** — 无 CDN、无字体外链、无埋点，PDF 库也是本地文件。断网可用，签名不出本机
- **在 PDF 上签字** — 选 PDF、拖签名到落款处、直接下载签好的文件。文件只在浏览器内存里处理，不上传
- **力度热力图** — 按书写压感给笔迹上色，从蓝到红。手写笔显示真实压感，鼠标和触屏没有压力数据，按书写速度推算，界面会标明当前是哪种
- **高清导出** — 2 倍超采样；导出时自动按墨迹裁掉四周空白，只留 24px 呼吸边，插进文档不用再手动裁剪
- **笔迹连续** — 中点二次贝塞尔，段与段首尾相接不留缝；合并事件全量取点，快速划动也不断线
- **笔锋** — 手写笔直接读压感，鼠标和手指没有压力，就按划动速度反推：起笔轻、行笔稳、快划细。强度 0–100% 可调，调到 0 就是均匀线宽
- **一键复制** — 签完直接复制图片，切到 Word / WPS 按 Ctrl+V 粘贴，省掉下载再找文件那一步
- **墨色可选** — 6 种预设（纯黑 / 深灰 / 蓝黑 / 标准蓝 / 藏青 / 红）+ 自定义取色器，线宽 1.5–8 px
- **可撤销** — 最多回退 6 步，支持 Ctrl/Cmd + Z；清空要点两次，且清空本身也能撤销回来
- **记住偏好** — 上次用的墨色、粗细、是否带日期会存在本机，下次打开直接沿用
- **可选日期** — 勾选后在签名右下方附上日期，日期锚定签名而非常量画布边，裁剪后不会留大片空白
- **两种底色** — 透明 PNG（叠在文档上不遮字）/ 白底 PNG（部分系统对透明底兼容差）

## 用法

打开 `index.html`，或访问 GitHub Pages 在线版。

1. 在框里手写签名
2. 按需调整墨色、粗细、笔锋
3. 点「复制图片」直接粘进 Word / WPS；或导出 PNG 再插入（Word 里设为「浮于文字上方」，PDF 用 WPS / Acrobat 的签名功能）

> 「复制图片」走的是 Clipboard API，需要 HTTPS 环境。用 GitHub Pages 在线版可以正常用；把 `index.html` 下载到本地以 `file://` 打开时，浏览器会拦，请改用导出 PNG。

## 在 PDF 上签字

1. 先在签名板写好名字
2. 下拉到「在 PDF 上签字」，选择或拖入 PDF 文件
3. 把签名拖到落款位置，用「签名宽度」调大小，多页文件可用 ← → 翻页
4. 点「下载签好的 PDF」

实现上没引入 PDF.js 这类渲染引擎（那要多 1MB），而是按 PDF 的真实页面比例画一张示意页——尺寸取自 PDF 的页面框，所以比例是准的，只是不显示原文档内容。签名按相对坐标定位，导出时用同一套相对坐标写入。

已知限制：页面带 `/Rotate` 旋转的 PDF 未做坐标变换，签名位置可能偏；签名页是追加图层，不修改原文档内容。

## 关于「力度热力图」

浏览器只在**手写笔**上提供真实压力值（`PointerEvent.pressure`），鼠标永远是常量 0.5。所以：

- 用笔写 → 热力图反映真实压感，图例标「真实压感」
- 用鼠标或手指写 → 没有压力数据，按**书写速度**反推，慢则粗、快则细，图例标「速度反推」

它反映的是书写节奏和笔压，不是测力计读数。写起来慢的地方偏红，划得快的地方偏蓝。

## 拿它签承诺书之前

- 签名用**黑色**签字笔的笔迹效果最自然，日期也建议手写
- 承诺书如果写着「已阅读并抄写全文」，必须**真笔手写**，图片签名不成立
- 需要按手印的（社区、学校常见），打印 → 签字 → 按印泥 → 拍照
- 线上表单上传白底 PNG 兼容性更好，有些系统会把透明底渲染成黑块

## 浏览器支持

Chrome / Edge / Firefox / Safari 近两年版本。依赖 Pointer Events 与 Canvas，无需 WebGL。
